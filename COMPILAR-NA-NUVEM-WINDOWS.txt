SABOR & HORTA — COMO RECEBER O APK SEM USAR ANDROID STUDIO

Esta pasta contém uma automação para o GitHub Actions compilar o APK na nuvem. Você não precisa instalar Android Studio, Java ou Android SDK no Windows.

PASSO 1 — Criar uma conta gratuita no GitHub
1. Acesse https://github.com/ e crie uma conta (ou entre na sua conta).
2. Confirme seu e-mail, se o GitHub solicitar.

PASSO 2 — Criar um repositório
1. Acesse https://github.com/new
2. Em Repository name, escreva: sabor-horta
3. Selecione Public (assim o uso do GitHub Actions é simples e gratuito dentro dos limites do GitHub).
4. Marque Add a README file.
5. Clique em Create repository.

PASSO 3 — Enviar os arquivos do projeto
1. Na página do repositório, clique em Add file > Upload files.
2. No Windows, extraia o ZIP do projeto.
3. Abra a pasta extraída e selecione TODOS os arquivos e pastas que estão dentro dela, incluindo a pasta oculta .github.
   IMPORTANTE: a pasta .github/workflows/android.yml é necessária para a compilação automática. Se o Windows não mostrar .github, habilite Exibir > Itens ocultos no Explorador de Arquivos.
4. Arraste os arquivos/pastas para a área de upload do GitHub.
5. Clique em Commit changes.

PASSO 4 — Baixar o APK compilado
1. No repositório, abra a aba Actions.
2. Selecione "Build Sabor & Horta APK".
3. Abra a execução mais recente (aguarde ficar verde/Success; a primeira compilação pode levar alguns minutos).
4. No final da página da execução, procure Artifacts.
5. Clique em sabor-horta-apk-debug para baixar o ZIP do artefato.
6. Extraia esse ZIP. Dentro estará app-debug.apk.

PASSO 5 — Instalar no celular Android
1. Envie app-debug.apk para o celular (USB, Google Drive ou outro método confiável).
2. Abra o APK no celular.
3. Se solicitado, permita temporariamente a instalação de apps dessa origem nas configurações do Android.
4. Confirme Instalar e depois Abrir.

NOTAS IMPORTANTES
- Este é um APK debug para teste, não uma versão assinada para distribuição comercial na Play Store.
- Não publique o código se ele contiver dados privados; o repositório Public torna o código visível a qualquer pessoa.
- O APK usa fotografias hospedadas online e precisa de internet para carregá-las.
- O modo quiosque total não está ativado no APK de teste para não bloquear seu celular. Para o totem será necessário provisionar o Android como dispositivo dedicado/Device Owner.
- Se o upload pelo site não aceitar pastas, envie o conteúdo mantendo a estrutura de pastas; a pasta .github/workflows deve ficar exatamente nesse caminho na raiz do repositório.
